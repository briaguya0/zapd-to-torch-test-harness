# Manifests

SHA256 hash manifests of reference O2R contents. Used by the test scripts to
verify Torch output matches the reference, file by file.

Generated by `manifest.sh` from a reference O2R:

```sh
./manifest.sh o2r/<version>_<sha>.o2r manifests/<version>.json
```

Hashes and asset paths only — no ROM data.

of the archive.
